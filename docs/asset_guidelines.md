# Asset Guidelines

## Directorio de assets a utilizar

Solo se deben leer y usar los assets ubicados en la carpeta:

```
Assets/Nachiten/
```

## Assets ignorados

La carpeta `Assets/Synty/` y todo su contenido **deben ser ignorados**. No se deben utilizar ni referenciar directamente assets de esa carpeta en el desarrollo del juego. A menos que el usuario pida explicitamente leerla o usarlos.

> Los assets de Synty (PolygonStarter) son recursos base importados del pack original. Los assets propios del proyecto se encuentran en `Assets/Nachiten/`.
